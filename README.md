 # 🎯 Number Guessing Game

A simple, interactive number guessing game built using **HTML, CSS, and JavaScript**, with a custom pastel-themed interface and attempt tracking.

The goal is simple: guess the randomly generated number between 1 and 100 using the hints provided by the game.

## ✨ Features

- **Random Number Generation** — Generates a new secret number for every game.
- **Interactive Gameplay** — Receive hints to help you find the correct number.
- **Attempt Tracking** — Keep track of the number of guesses made.
- **Custom UI Design** — A pastel-inspired interface with a clean layout and playful illustrations.

## 🛠️ Built With

- **HTML5** — Structure and semantic elements.
- **CSS3** — Styling.
- **JavaScript** — Game logic, random number generation, event handling, and interactive feedback.

## 🎮 How to Play

1. Enter a whole number between 1 and 100.
2. Click **Check** to submit your guess.
3. Follow the hints to determine whether your guess is too high or too low.
4. Find the correct number to win!
